Formularios en HTML

Texto

Campos de texto basicos: simple, con placeholder, obligatorio (required), de solo lectura (readonly) y deshabilitado (disable).





Contacto

especializados para datos de contacto: contraseña, correo electrónico, teléfonoy URL, cada uno con su propio teclado y validación en el navegador
Numéricos

Campos para valores numéricos: un número con límites (min/max) y un deslizador (range)para elegir un valor dentro de un rango.



Fecha y hora

Selectores nativos de fecha y hora: fecha, fecha y hora combinadas, hora, semanda del año y mes






Seleccion

Controles de seleccion: elegir un color, marca una casilla, elegir una opcion de un grupo de radios y subir un archivo





Listas desplegables

Listas desplegables con el elemento select: una opción simple, una con valorpreseleccionado (selected), una agrupada con optgroup, una de selección múltiple (multiple) y unadeshabilitada (disabled).
